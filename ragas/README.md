# RAGAS 사용법 - 미니 RAG 실측

나라장터에 공개된 RFP 9건으로 미니 RAG를 만들고, 골든셋 27문항으로 RAGAS를 돌려 측정하고 개선한 기록입니다.
링크드인 아티클 연재 "RAGAS 사용법"의 재료입니다.


## 파일

| 경로 | 내용 |
| --- | --- |
| `docs/` | RFP PDF 9건 (2022-2026, 디지털서비스 개방 플랫폼 구축 관련 사업) |
| `mini_rag.py` | PDF 읽기 → 청킹 → 임베딩 → 검색 → 생성. 약 100줄 |
| `run_ragas.py` | 골든셋을 읽어 미니 RAG에 질문하고 RAGAS로 채점, CSV 저장 |
| `goldenset.xlsx` | 골든셋 27문항(시트 1), 메타모픽 변형 20문항(시트 2) |
| `results/` | 측정 결과 CSV |

## 결과 파일

| 파일 | 설정 | 비고 |
| --- | --- | --- |
| `cs800_k4_r1.csv` ~ `r5.csv` | 청크 800자, top-4 | 기본 설정 5회 반복. 충실도 평균 0.407 / 0.481 / 0.407 / 0.296 / 0.333 |
| `cs800_k4_meta.csv` | 청크 800자, top-4 | 메타모픽 20문항 |
| `cs800_k8.csv` | 청크 800자, top-8 | 개선방향 1 |
| `cs1500_k4.csv` | 청크 1500자, top-4 | 개선방향 2 |
| `cs1500_k8.csv` | 청크 1500자, top-8 | 개선방향 3 |

## 실행

```
pip install ragas==0.4.3 openai pypdf openpyxl pandas
set OPENAI_API_KEY=...
python mini_rag.py          # 인덱스 구축
python run_ragas.py         # 27문항 측정 → results/
```

파이썬 3.12. 생성 모델 GPT-4o mini, 임베딩 text-embedding-3-small, 채점 GPT-4o mini.
검색 개수와 청크 크기는 환경변수 `TOP_K`, `CHUNK_SIZE`로 바꿉니다.
